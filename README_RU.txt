OPEN CITY 3D — PUBLIC MULTIPLAYER (до 32 игроков)

СОСТАВ
- client.html — браузерная игра с подключением по WebSocket.
- server/server.js — Node.js сервер публичной комнаты.
- package.json — зависимость ws и команда запуска.

ЗАПУСК СЕРВЕРА
1. Установите Node.js 18 или новее.
2. Откройте терминал в папке open_city_online.
3. Выполните: npm install
4. Выполните: npm start
5. Откройте http://localhost:8080 на компьютере.
6. Для доступа друзей из интернета разместите папку на VPS/хостинге с Node.js и откройте TCP-порт 8080 (или настройте HTTPS reverse proxy).

ВСЕ ИГРОКИ ДОЛЖНЫ ОТКРЫВАТЬ ОДИН И ТОТ ЖЕ АДРЕС СЕРВЕРА.
Для HTTPS-сайта WebSocket автоматически использует WSS.

ТЕКУЩАЯ ГРАНИЦА РЕАЛИЗАЦИИ
Это рабочий сетевой каркас: публичная комната, лимит 32 подключения, обмен позициями/поворотом/состоянием транспорта и отрисовка других игроков. Сервер ретранслирует состояния, но пока не является авторитетным игровым сервером. NPC, полиция, урон, выстрелы, инвентарь, деньги, транспортная физика и реклама пока локальны на каждом клиенте и между игроками не синхронизируются. Для полноценного общего мира нужны серверная симуляция этих систем, защита от читов, аккаунты/идентификация, persistence и эксплуатационный хостинг.

БЕЗОПАСНОСТЬ/ЭКСПЛУАТАЦИЯ
Не выставляйте сервер в публичный интернет без HTTPS/WSS reverse proxy, лимитов соединений, мониторинга и защиты от злоупотреблений. Этот проект — прототип, не production-ready backend.
